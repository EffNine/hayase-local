# Hayase-lite

A personal torrent streaming app.

## Development

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
```

## Release

Pushing a `v*` tag triggers the release workflow:

```sh
git tag v0.1.0
git push origin v0.1.0
```

Downloads are published to [GitHub Releases](https://github.com/afnanrudy/hayase-lite/releases).
